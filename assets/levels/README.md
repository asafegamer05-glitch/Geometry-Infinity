# Level Image Guide — Geometry Infinity

Place your level thumbnail images in this folder (`assets/levels/`).

## Required File Names ( If you what you can change it,just fork my repo )

| Level          | File name (use exact name)       |
|----------------|----------------------------------|
| Stereo Madness | `stereo_madness.png`             |
| Back on Track  | `back_on_track.png`              |
| Polargeist     | `polargeist.png`                 |
| Dry Out        | `dry_out.png`                    |
| Base After Base| `base_after_base.png`            |
| Can't Let Go   | `cant_let_go.png`                |
| Jumper         | `jumper.png`                     |
| level easy     | `level_easy.png` (Challenge)     |

## Supported Formats

The site will try each extension in this order:

1. `.png`  ← preferred
2. `.jpg`
3. `.jpeg`

So `stereo_madness.jpg` also works if you don't have a PNG.

## Tips

- **Best size:** 280 × 200 px or 16:9 ratio (anything works, it gets cropped)
- **Where to get them:** Screenshot the level select screen in GD, or grab
  thumbnail images from YouTube / the GD Wiki.
- If an image is missing, the site shows a colored gradient placeholder instead —
  so the game works fine without any images.

## Example

```
assets/
└── levels/
    ├── stereo_madness.png   ← ✅ will be shown
    ├── back_on_track.jpg    ← ✅ also works
    └── README.md
```
